## 📌 重点事件深度解析

### 🔥 事件一：美国 CPI 数据（3月11日）
**重要程度：⭐⭐⭐⭐⭐ 本周最高优先级**

**事件详情**：
- Core CPI m/m：前值 0.3%，预测 **0.2%**（即预期降温）
- CPI y/y：前值 2.4%，预测 **2.5%**（预期小幅回升）
- CPI m/m：前值 0.2%，预测 0.3%

**为何需要高度关注**：
3月11日 CPI 数据将是 3月18日 FOMC 会议前最后一份关键通胀报告，直接影响美联储的政策决策和点阵图预测。本次数据存在明显分歧——核心CPI月率预测降温至 0.2%，但 CPI 年率预测小幅回升至 2.5%，形成"核心降温、整体略升"的组合。

**潜在市场影响**：

| 情景 | 数据结果 | 市场反应 |
|------|----------|----------|
| 超预期降温 | Core CPI < 0.2%，CPI y/y ≤ 2.4% | 降息预期大幅升温 → 成长股飙升，美债收益率下行，黄金上涨 |
| 基本符合预期 | 接近预测值 | 市场平稳，等待 FOMC 具体指引 |
| 超预期偏热 | Core CPI > 0.3%，CPI y/y ≥ 2.7% | 降息预期受挫 → 科技股承压，美债收益率上行，黄金短期承压 |

**对我们组合的影响**：AAPL、GOOGL、NVDA 等高 PE 成长股对 CPI 数据极为敏感，建议在 3月11日数据发布前适当控制仓位，发布后再做方向性决策。

### 🔥 事件二：FOMC 利率决议（3月18日）
**重要程度：⭐⭐⭐⭐⭐ 本周期最核心催化剂**

**事件详情**：
- 联邦基金利率决议（当前 3.64%）
- FOMC 经济预测（点阵图 Dot Plot）
- 主席鲍威尔新闻发布会

**为何需要高度关注**：
这是年内最重要的政策决策节点之一。当前联邦基金利率 3.64%，美联储在去年底小幅降息后维持观望态度。本次会议的关键看点不在于"降不降"，而在于：

1. **点阵图如何调整**：2026年降息次数预测是否从2次调整为1次或3次
2. **鲍威尔对通胀路径的表述**：是否仍认为通胀"有所进展"或转向更谨慎
3. **对劳动市场的评估**：UNRATE 4.4% 是否触发对就业市场的担忧

**潜在市场影响**：

| 情景 | FOMC 立场 | 市场反应 |
|------|-----------|----------|
| 鸽派（降息信号或预期降息次数增加） | 点阵图维持2-3次 / 鲍威尔强调通胀放缓 | 科技股、成长股强烈上涨，美元走弱，黄金上涨 |
| 中性（维持现状，模糊措辞） | 点阵图降至1-2次 / 措辞中性 | 市场短暂波动后方向不明 |
| 鹰派（意外鹰派或暗示延迟降息） | 点阵图降至1次或暗示暂停 / 强调通胀风险 | 科技股大幅下跌，美元走强，黄金短期承压 |

**操作建议**：3月18日前建议控制科技股仓位至30%以下，等待 FOMC 后再根据实际指引加仓或减仓。

### 事件三：中国 CPI / PPI（3月8日，明日）
**重要程度：⭐⭐⭐**

**事件详情**：
- CPI y/y：前值 0.2%，预测 **0.9%**（预期大幅回升）
- PPI y/y：前值 -1.4%，预测 -1.1%（预期通缩边际改善）

**为何需要关注**：
中国 CPI 从 0.2% 跳升至 0.9% 的预期是较大幅度的回升，需要验证是否为春节季节性因素推动还是真实需求复苏。若数据超预期，意味着中国经济刺激政策初见成效，将利好：
- NVDA（中国数据中心需求边际恢复）
- TSLA（中国 EV 市场销售环境改善）
- 大宗商品（铜、铁矿石等）

若不及预期（CPI 接近0），则通缩压力持续，中国需求复苏故事将再度受挫。

### 事件四：美国 Core PCE + GDP 初值（3月13日）
**重要程度：⭐⭐⭐⭐**

**事件详情**：
- Core PCE m/m：前值 0.4%，预测 **0.4%**（持平，美联储首选通胀指标）
- Prelim GDP q/q：前值 1.4%，预测 **1.4%**（持平）
- JOLTS 职位空缺：前值 654万，预测 684万（改善预期）
- Prelim UoM 消费者信心：前值 56.6，预测 55.9（轻微恶化）

**为何需要关注**：
Core PCE 是美联储官方首选通胀指标，若本次持平在 0.4%（月率），表明通胀下行进展停滞，FOMC 更难在 3月会议给出降息承诺。但若 JOLTS 职位空缺意外走强（至 700万+），则表明劳动市场仍有韧性，为美联储"延迟降息"提供依据。

**消费者信心跌至 55.9**（较历史均值偏低）也值得关注——密歇根大学消费者信心指数若持续下行，是消费疲软的领先信号，可能影响科技消费品（iPhone、特斯拉等）的近期需求预期。
