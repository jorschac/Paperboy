# 公园爷叔

帮你分析相关股票的消息面，给出投资建议

灵感来源：[上海爷叔认为股市大牛市马上到来，您认可他的观点吗？](https://www.bilibili.com/video/BV16Z421g76G)
## 为什么做

1. 市场信息多且杂，散户很难每天拿出  1-2 小时时间分析消息面。有限的时间当然只能看到碎片的新闻。日积月累造成判断滞后
2. 交易策略涉及数据计算，散户很难拿出精力做这些事
3. 市场研究很难长期坚持
4. 如果有一个 AI 可以每天早上八点半替我们做一遍最新的市场研究，并且可以把消息直接推送到手机上，而且这个 AI 具备长短期记忆和学习机制能长期追踪市场趋势，那散户们每天九点半开盘前就能相对有一颗清晰的头脑。每天看 AI 产出的市场研究也能增长知识

## 他目前能做

1. 拉取+排序出科技七姐妹最相关的 20 条一周内新闻，一共 140 条，整理出这些新闻的摘要，情绪，信源。汇总成【新闻情绪】数据
2. 拉取七姐妹当日交易快照和过去 7 日交易信息，汇总成【市场快照】数据
3. 拉取联邦基金利率、失业率、10 年美债收益、季后消费者指数等宏观信息，汇总成【宏观快照】数据
4. 拉取未来 3 周经济事件日历，比如美联储 Officials 和国家领导人的讲话、数据公布日期等，汇总成【三周日历】数据
5. 汇总以上所有数据，分析多空消息和投资建议，输出【当日市场摘要】，辅助 traders 做决策。从此拒绝遗漏消息
